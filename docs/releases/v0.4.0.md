# v0.4.0

## Highlights

- `research start / status / resume / revise` 个人研究会话 CLI；
- 可恢复 ResearchSession：不可变 revision、hash 绑定 artifact、
  显式确认与 single-use authorization、中断恢复幂等；
- 数据缺口与接口需求提示：缺 verified provider mapping、数据接口配置、
  local CSV 或 Provider credential 时明确告知；
- AnalysisPlan confirmation 与 single-use authorization；
- Pearson、Spearman、OLS classic/HC1/Newey-West 统计分析；
- session-based 对齐与 no-lookahead；
- AnalysisResult 可验证持久化；
- grounded LLM interpretation：证据绑定、数字由代码渲染；
- Markdown 验证报告；
- FRED/local CSV 数据生命周期；
- Windows/Linux × Python 3.11/3.13。

## End-to-end workflow

自然语言假设 → Research Agent → ResearchSpec → 数据生命周期 →
Data Ready → AnalysisPlan → Analysis Authorized → Pearson / Spearman /
OLS → AnalysisResult → LLM 解释 → Markdown 验证报告。

## Research Agent CLI

```powershell
market-validator research start --question "..." `
  --workspace .\my-research --provider deepseek_api --model <MODEL> `
  --allow-llm-network
market-validator research status --session .\my-research
market-validator research resume --session .\my-research
market-validator research revise --session .\my-research `
  --instruction "..." --workspace .\my-research-revised `
  --provider deepseek_api --model <MODEL>
```

Agent 只自动执行不联网、不消费授权、不产生新承诺的操作；需要用户
决定时停下来说明原因。

## Analysis planning and authorization

AnalysisPlan 由代码从 Data Ready 与明确决策确定性生成；用户显式确认
（固定确认语句）后创建 single-use authorization，只允许一次确定性执行
尝试，消费后不自动重试。

## Statistical analysis

- Pearson correlation（t 检验、Fisher-z 置信区间）；
- Spearman correlation（average rank）；
- OLS：classic / HC1 / Newey-West 标准误；
- 多重检验：Bonferroni / Holm / Benjamini-Hochberg；
- 统计数字规范化为 12 位有效数字，纯 Python 实现、可重复运行。

## Grounded LLM interpretation

解释由证据包（evidence package）驱动；总体结论由代码聚合，LLM 文本
不得新增数字；数字全部由 Python 渲染进 Markdown 表格；默认不联网。

## Data access behavior

FRED 只允许 HTTPS 官方主机与显式 `allow_network`；每次 live fetch 保存
原始响应、哈希、标准化数据包与无密钥 manifest。local CSV 必须非 symlink、
regular file、UTF-8 并通过现有 inspection/validation。不同供应商数据
不静默混合；数据包保存单一来源元数据与 SHA-256。

## Trust boundaries

- LLM 只输出待验证的研究建议，不参与计算；
- 确认与授权都是显式、hash 绑定、single-use；
- 系统不执行真实交易，也不提供自动下单能力；
- 相关性不表述为因果关系。

## Known limitations

- 不支持任意互联网 source discovery；
- 不支持网页抓取；
- 不执行 robustness；
- 没有 Web UI；
- 部分真实市场日历、接口或 mapping 仍需用户提供；
- 不提供投资建议；
- 未发布 PyPI。

## Upgrade notes

从 v0.3.0 升级无需迁移既有 artifact；本版本新增 Research Agent 编排层
与会话持久化，既有数据生命周期与分析 API 保持不变。解释 LLM 目前通过
fixture 客户端演示，真实 LLM interpretation 客户端保留为后续能力。
